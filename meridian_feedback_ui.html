Action required — trigger bug in correction_labels
The update_field_label_on_correction trigger references enriched_field_log.run_id but the correct column name is enrichment_run_id. All correction inserts fail until fixed.

Apply the one-line fix in the Supabase SQL Editor: 
CREATE OR REPLACE FUNCTION update_field_label_on_correction()
RETURNS TRIGGER AS $$
BEGIN
    UPDATE enriched_field_log
    SET field_label = 'corrected',
        label_source = 'kyle_correction',
        correction_id = NEW.id,
        reviewed_at = NOW()
    WHERE enrichment_run_id = NEW.run_id   -- was: run_id = NEW.run_id (bug)
      AND field_name = NEW.field_name
      AND entity_id = NEW.entity_id;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;
