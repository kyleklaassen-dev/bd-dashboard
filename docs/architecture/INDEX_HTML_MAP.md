## 8. How to find your way around (cheat sheet)

- **Add / find a tab** → search `registerTab('` and the pane `id="tab-XXX"`. Never edit
  `switchTab` to add a tab (the file itself says so at line 17616).
- **Change global styling** → `<style>` #1 (lines 67–2651). Per-tab tweaks live in that
  tab's own `<style>` block (§2).
- **Touch data loading** → core block #1 (`loadX()` fns, 2986–5420) or the relevant tail module.
- **Change Supabase wiring** → lines 2988–2990 (and the defensive re-derivations).
- **Reduce file size** → the 26 Industry-Insights JPEGs were the biggest target and are now extracted to `/assets/` (§6, done). Remaining bulk is `<style>` #1 and the JS modules.
